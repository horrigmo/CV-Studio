Morten Portfolio v4.0 – Manual multilingual CV

Changes:
- Multilingual mode can be enabled/disabled under CV -> CV settings.
- Language selector is hidden when multilingual mode is disabled.
- English CV uses /cv/en/ while Norwegian uses /cv/.
- Manual Norwegian/English tabs on experience, education and course entries.
- “Copy Norwegian text” fills empty English fields as a starting point.
- Translation completion indicator in each entry.
- CV quality page shows English completion percentage.
- Existing English fields remain stored when multilingual mode is disabled.
- AI translation settings and calls have been removed.
- PDF engine continues to use the currently selected language.

After activation, visit Settings -> Permalinks and click Save once if /cv/en/ gives a 404.
