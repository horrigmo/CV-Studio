Morten Portfolio v3.1

New in this version:
- English front-page button label is now "To frontpage".
- Optional automatic English CV translation via OpenAI Responses API.
- Translation is generated lazily when EN is opened and cached in WordPress.
- It regenerates only after Norwegian CV source content changes.

Setup:
1. Go to CV > CV-innstillinger.
2. Enable automatic English translation.
3. Enter an OpenAI API key and model name.
4. Save settings.
5. Open the CV and select EN. The first load can take longer while translation is generated.

Manual English fields remain available and are used when automatic translation is disabled.
